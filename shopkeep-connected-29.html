🔗 Connect Your Shop — 2 Minutes

This app uses a Google Sheet as a shared database so every shopkeeper's phone stays in sync. You need a Google account (free). Follow these steps once only.

  1. Open this link to copy the ShopKeep template Sheet:
    👉 Click here to copy the Google Sheet template
    Sign in with your Google account if prompted, then click "Make a copy".
  2. In your copied Sheet, click: Extensions → Apps Script → Deploy → New Deployment
    Select type: Web app · Execute as: Me · Who has access: Anyone → Click Deploy → Copy the Web App URL.
  3. Paste the Web App URL below and click Connect:
  4. Share this HTML file with all shopkeepers — WhatsApp, email, or Google Drive. Each person opens it, pastes the same URL, and they're live on the same data.
